# 🧬 GC-MS AI Analyzer

Open-Source NIST Alternative — AI-Powered GC-MS Data Analysis

## ☕ Try Without Data

Click **"Try Demo: Coffee Roasting Flavor Analysis"** — instant 45-compound dataset with interactive charts.

## Features

- 📊 50+ analysis tools (peak detection, compound ID, statistics, flavor analysis)
- 🔍 300K+ spectral library (MassBank, MoNA, built-in)
- 🤖 AI Agent — natural language interface
- 👃 Flavor analysis: OAV, ROVA, flavor wheel, off-flavor DB
- 📈 Interactive Plotly charts (TIC, PCA, volcano, heatmap, mirror plot)
